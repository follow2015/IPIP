# 决策与论证见 code_review/ClickHouse时序存储落地设计-20260920.md §4.1 / §4.9（v1.4 改判）。
# 为什么不用现有 requests 手写 TSV：原选型给 requests 的唯一硬理由是"零新依赖"，该约束
# 解除后，手写序列化（\N NULL、\t \n \\ 转义、Decimal/DateTime64 时区、NaN/Inf、数组字面量）
# 只剩正确性负债 —— 转义错一次即整批拒写或静默串列。本库自带 FORMAT Native 列式序列化，
# 走 HTTP :8123（仍不开 native TCP :9000），并协商 LZ4/ZSTD 压缩。
# 传递依赖由 pip 解析（urllib3 / certifi / lz4）；Python>=3.14 的 zstd 走标准库（PEP 784），
# 故**不需要** zstandard。⚠️ 本包是平台相关 wheel（内含预编译 C 加速扩展），离线部署机
# 需按平台预热（pip download --only-binary=:all:）。⚠️ 元数据 Requires-Python = >=3.10,<3.15
# ⇒ 升到 3.15 时 pip 安装会直接失败，升级 Python 前须先确认上游放宽上界。
